Tungsten Queen Mine Geochemistry Analysis

A polished exploratory analysis of mine-waste geochemistry, tungsten distribution, and element-level relationships in Python.

← Back to Programming View Visual Results →
Overview

Research-grade exploratory analysis on a real critical-mineral dataset.

This project analyzes geochemical measurements from the Tungsten Queen Mine, an abandoned tungsten mine and mine-waste tailings site in North Carolina. I used the assignment as a week-one Data+ exercise to practice a complete research-computing workflow: cleaning laboratory values, summarizing element concentrations, visualizing commodity elements, mapping sample locations, testing grouped tungsten differences, and building a correlation heatmap.

The page below is a portfolio-facing case study. It emphasizes the analytical workflow and selected results rather than presenting the raw notebook export as a file dump.

Methods

Workflow Summary

The analysis was built as a Jupyter notebook with markdown explanations, pseudocode, code cells, visible outputs, and written interpretation under each plot or test.

1. Data Cleaning

Loaded the spreadsheet, isolated measurement columns, and replaced negative below-detection-limit flags with zero while leaving coordinates and descriptors unchanged.

2. Summary Statistics

Computed descriptive statistics for all element columns, including mean, median, standard deviation, quartiles, and maximum values.

3. Spatial Mapping

Converted latitude and longitude into a GeoDataFrame and mapped sample points by tungsten concentration to examine local spatial variation.

4. Relationships

Parsed depth strings, compared grouped tungsten values with t-tests, and built a selected-element correlation heatmap.

Selected Visuals

Results that communicate the analysis quickly.

These figures were selected from the notebook because they show the core analytical movement: commodity-scale variability, local spatial clustering, depth-based tungsten behavior, group comparisons, and element-level correlation structure.

Commodity Element Concentrations

Log-scale boxplots make the large concentration range readable. Tungsten is the dominant commodity element, while copper, zinc, and lead remain visibly notable across the dataset.

Spatial Distribution of Tungsten

Mapping the samples by concentration shows that tungsten enrichment is not evenly distributed across the sampled area; higher values cluster within a narrower part of the site.

Tungsten by Depth

Mean tungsten values generally remain within the same broad range near the surface, with higher variability and elevated means in a mid-depth interval before returning toward lower concentrations.

Depth Category Comparison

A top-foot versus below-foot comparison did not produce a statistically significant difference in mean tungsten concentration in this exploratory test.

Collection Method Comparison

Composite and single/grab samples show different distributions visually, but the independent t-test did not meet the conventional significance threshold.

Selected Element Correlation Heatmap

The strongest positive relationships include zinc-sulfur, copper-sulfur, copper-zinc, tungsten-arsenic, lead-arsenic, and iron-aluminum. Silicon shows strong negative relationships with aluminum and iron.

Interpretation

What this project demonstrates.

The goal of this week-one exercise was not to make a definitive resource estimate. It was to demonstrate that I can turn a real scientific spreadsheet into a clean, interpretable, visual analysis pipeline.

Data discipline

The workflow separated descriptive fields from measurement columns before cleaning, which helped avoid accidentally altering coordinates, labels, or sample metadata.

Scientific visualization

The strongest figures use scale and context appropriately: log scale for multi-order concentration ranges, spatial plotting for location effects, and heatmaps for co-occurrence patterns.

Statistical restraint

The grouped t-tests are treated as exploratory checks. The results do not claim strong group separation where the p-values do not support it.

Technical Appendix

Notebook workflow, compressed.

This section preserves the logic of the original notebook without forcing visitors to scroll through every raw code cell.

Task I — Clean below-detection-limit values

Loaded the Excel file, selected columns 11 onward as element measurements, clipped negative values to zero, and verified that no negative measurement values remained.

Task II — Summarize every element

Used pandas descriptive statistics to summarize the distribution of every measurement column, then renamed the 50% row as median for readability.

Task III — Plot commodity elements on a log scale

Built log-scale boxplots for W, Cu, Mo, Zn, Pb, and As so concentration ranges spanning orders of magnitude could be compared in one figure.

Task IV — Map sample locations

Created a GeoDataFrame from latitude and longitude, assigned WGS84 coordinates, and plotted sample points colored by tungsten concentration.

Task V — Parse depth and plot tungsten by depth

Converted mixed depth descriptions into numeric inches, grouped by depth, and plotted mean tungsten concentration with standard-deviation error bars.

Task VI — Compare tungsten across categories

Compared tungsten by depth category and collection method using boxplots and independent two-sample t-tests. Depth p-value: 0.734. Method p-value: 0.129.

Task VII — Build the selected-element correlation heatmap

Computed and plotted pairwise correlations for W, Cu, Mo, Zn, Pb, As, Fe, S, Al, Ca, and Si to identify co-occurring and inversely related elements.

Scope Note

A compact research-computing exercise, not a final geologic conclusion.

This analysis was completed as an early Data+ practice task. The conclusions are intentionally framed as preliminary observations from exploratory analysis. A stronger scientific claim would require deeper geologic interpretation, QA/QC review, spatial modeling, and comparison against the full published study context.
