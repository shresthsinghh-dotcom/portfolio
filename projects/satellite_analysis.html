Satellite & Environmental Data Analysis

A Python workflow for working with real satellite rasters — smoothing noisy imagery, computing surface temperature and vegetation index, and testing how the two relate across regions — wrapped in an interactive app so the analysis can be explored rather than just read.

Overview

Reading the ground from orbit.

Satellite rasters carry more information than any single image shows. A GeoTIFF of a landscape holds reflectance across several bands, and the useful quantities — how hot the surface is, how much living vegetation covers it — have to be computed from those bands rather than observed directly.

This project builds that computation as a workflow: load real geospatial datasets, smooth the imagery to suppress pixel-level noise, derive land surface temperature and a vegetation index, and then ask whether the two are related within a given region. Wrapping it in Streamlit means the parameters are adjustable, so the effect of each choice on the result is visible immediately instead of buried in a notebook cell.

At a glance
Data Real geospatial raster datasets in GeoTIFF format.
Stack Python, NumPy, rasterio, matplotlib, Streamlit.
Focus Band arithmetic, raster handling, and making an analysis interactive rather than static.
Method

What the tool computes.

1. Smoothing

Raw satellite imagery is noisy at the pixel level. A smoothing pass suppresses that noise so downstream band arithmetic responds to real ground variation rather than sensor artifacts.

2. Surface temperature

Thermal band values are converted into a land surface temperature field, giving a per-pixel estimate of how hot the ground itself is.

3. NDVI

The normalized difference vegetation index compares near-infrared and red reflectance. Living vegetation reflects strongly in the near-infrared and absorbs red, so the ratio separates plant cover from bare ground.

4. Correlation

With both fields on the same grid, the tool tests how NDVI and temperature relate within a selected region — the vegetated-versus-bare temperature contrast made quantitative.
